# BUG-001 주문 완료 후 뒤로가기로 주문 확인 화면에 다시 들어가 빈 주문($0)을 다시 완료할 수 있음

## 환경
- 대상: https://www.saucedemo.com
- 자동화: Chromium, Firefox, WebKit (Playwright 1.65.1 Desktop Chrome / Desktop Firefox / Desktop Safari 프로필), 3개 모두 재현
- 수동 재현: Chrome, standard_user (검토자 직접 재현)
- 계정: standard_user (.env의 SAUCE_USERNAME, D-12)
- 실행일: 2026-11-24

## 관련 항목
- TC_ID:
  - TC-CHECKOUT-018 [Finish] 재선택 시 완료 화면 재표시 여부, D-11 (`tests/checkout.spec.ts:156`)
  - TC-CHECKOUT-033 빈 주문 확인 화면의 금액 표시 형식, D-10 부수 증상 (`tests/checkout.spec.ts:174`)
- REQ_ID: REQ-CHECKOUT-05 [Finish] 선택 시 주문 완료 화면("Thank you for your order!")이 노출되고, 장바구니가 비워지며 배지가 사라져야 한다
- 결정 사항: D-11 주문 완료 후 뒤로가기 등으로 [Finish]를 다시 눌러도 주문이 중복되면 안 된다
- 확인 필요: Q-03 빈 장바구니 결제: 상품이 없어도 주문 완료까지 가능한지, 막아야 하는지
- 부수 증상 관련: D-10 모든 금액은 소수점 둘째 자리까지 표시한다

## 재현 스텝
1. standard_user로 로그인
2. Sauce Labs Onesie, Sauce Labs Bike Light를 장바구니에 담기
3. 장바구니 아이콘 → [Checkout] → First Name Junyoung, Last Name Kim, Zip 12345 입력 → [Continue]
4. [Finish] 선택 → "Thank you for your order!" 주문 완료 화면 확인
5. 브라우저 뒤로가기
6. 주문 확인 화면(/checkout-step-two.html)에서 [Finish] 선택

## 기대 결과
- 주문 완료 후에는 뒤로가기로 주문을 다시 완료할 수 없어야 한다 (D-11). 이미 끝난 주문이나 빈 주문으로 [Finish]가 다시 진행되면 안 된다
- 빈 장바구니로 주문을 완료하게 둘지는 Q-03에서 아직 정해지지 않았다

## 실제 결과
- 뒤로가기 시 주문 확인 화면에 다시 들어가진다. 상품은 0개로 표시된다
- 이 화면에서 [Finish]를 누르면 "Thank you for your order!" 주문 완료 화면이 다시 나온다. 빈 주문($0)이 다시 완료된다 (검토자 수동 재현)
- 부수 증상 (D-10 불일치): Item total이 `Item total: $0`으로 표시된다. `$0.00`이 아니다. Tax와 Total은 `$0.00`으로 표시된다 (Chromium 스크린샷 기준)
- 자동화 테스트 실패 지점 (2026-11-24 재실행, Chromium·Firefox·WebKit 모두 동일):
  - TC-CHECKOUT-018: `tests/checkout.spec.ts:170` `await expect(page).not.toHaveURL(/\/checkout-complete\.html$/)`
    - 뒤로가기 후 주문 확인 화면 진입 검증(164행)은 통과했다
    - [Finish] 재선택 후 5초 동안 URL이 `https://www.saucedemo.com/checkout-complete.html`로 유지되어 실패했다. 완료 화면이 다시 표시된 것을 자동화로도 확인했다
  - TC-CHECKOUT-033: `tests/checkout.spec.ts:186` `toHaveText('Item total: $0.00')`, 수신값 `"Item total: $0"`
    - Tax(`Tax: $0.00`), Total(`Total: $0.00`) 검증은 통과했다. 세 값을 모두 확인하려고 soft assertion을 썼다
