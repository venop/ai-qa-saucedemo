# BUG-001 주문 완료 후 뒤로가기로 돌아간 주문 확인 화면에서 Item total이 "$0"으로 표시됨 (소수점 둘째 자리 누락)

## 환경
- 대상: https://www.saucedemo.com
- 브라우저: Chromium, Firefox, WebKit (Playwright 1.65.1 Desktop Chrome / Desktop Firefox / Desktop Safari 프로필), 3개 모두 재현
- 계정: standard_user (.env의 SAUCE_USERNAME, D-12)
- 실행일: 2026-11-24

## 관련 항목
- TC_ID: TC-CHECKOUT-018 (`tests/checkout.spec.ts:156`)
- REQ_ID: REQ-CHECKOUT-05, REQ-CHECKOUT-04
- 결정 사항: D-10 모든 금액(상품 가격, Item total, Tax, Total)은 소수점 둘째 자리까지 표시한다 / D-11 주문 완료 후 뒤로가기 등으로 [Finish]를 다시 눌러도 주문이 중복되면 안 된다

## 재현 스텝
1. standard_user로 로그인
2. Sauce Labs Onesie, Sauce Labs Bike Light를 장바구니에 담기
3. 장바구니 아이콘 → [Checkout] → First Name Junyoung, Last Name Kim, Zip 12345 입력 → [Continue]
4. [Finish] 선택 → 주문 완료 화면 확인
5. 브라우저 뒤로가기
6. 주문 확인 화면(/checkout-step-two.html)의 상품 목록과 금액 확인

## 기대 결과
- 주문 확인 화면에 상품이 0개이고, Item total·Tax·Total이 모두 `$0.00`으로 표시된다
- [Finish]를 다시 눌러도 배지가 생기지 않고, 장바구니 화면의 상품이 0개다

## 실제 결과
- 상품은 0개로 표시된다 (기대와 같음)
- Item total이 `Item total: $0`으로 표시된다. 기대값은 `Item total: $0.00`이다
- 자동화 테스트는 Item total 검증에서 멈췄다. 그래서 이번 실행에서는 Tax·Total 값과 [Finish] 재선택 이후 단계(배지, 장바구니 0개)를 자동으로 확인하지 못했다
- 수동 관찰 기록(tc/testcases.csv TC-CHECKOUT-018 비고)에는 Tax·Total은 `$0.00`으로 표시되고, [Finish] 재선택 시 완료 화면이 다시 나오며 장바구니·배지는 비어 있다고 되어 있다

## 심각도(제안)
- 낮음 (Minor): 표시 형식이 D-10과 다르다. 금액 자체는 0으로 맞다
- 참고: 빈 주문으로 [Finish]가 다시 진행되는 동작은 D-11(주문 중복 금지) 관점에서 따로 확인이 필요하다
