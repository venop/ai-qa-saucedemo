# BUG-005 Last Name에 공백만 입력해도 에러 없이 주문 확인 화면으로 이동함

## 환경
- 대상: https://www.saucedemo.com
- 브라우저: Chromium, Firefox, WebKit (Playwright 1.65.1 Desktop Chrome / Desktop Firefox / Desktop Safari 프로필), 3개 모두 재현
- 계정: standard_user (.env의 SAUCE_USERNAME, D-12)
- 실행일: 2026-11-24

## 관련 항목
- TC_ID: TC-CHECKOUT-030 (`tests/checkout.spec.ts:216`)
- REQ_ID: REQ-CHECKOUT-02 필수 정보를 비운 채 [Continue] 선택 시 비어 있는 항목의 에러 메시지를 표시하고 다음 단계로 이동하지 않는다
- 결정 사항: D-08 First Name, Last Name, Zip/Postal Code에 공백만 입력한 경우 빈 값으로 처리한다
- 같은 원인 후보: BUG-003 (Zip/Postal Code), BUG-004 (First Name)

## 재현 스텝
1. standard_user로 로그인
2. Sauce Labs Onesie를 장바구니에 담기
3. 장바구니 아이콘 → [Checkout]
4. First Name Junyoung 입력
5. Last Name에 공백 3칸만 입력
6. Zip/Postal Code 12345 입력
7. [Continue] 선택

## 기대 결과
- 공백만 입력한 값은 빈 값으로 처리되어 `Error: Last Name is required` 에러가 표시된다
- 정보 입력 화면(/checkout-step-one.html)에 머무른다

## 실제 결과
- 입력란에는 공백 3칸이 그대로 들어가 있다 (테스트의 `toHaveValue('   ')` 통과)
- [Continue] 선택 후 에러가 표시되지 않는다 (`getByTestId('error')` 요소 없음)
- 주문 확인 화면("Checkout: Overview")으로 이동한다. Item total $7.99, Tax $0.64, Total $8.63이 표시된다

## 심각도(제안)
- 중간 (Major): 필수 정보 검증을 우회해서 성 없이 주문을 진행할 수 있다
